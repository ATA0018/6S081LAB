1、Which registers contain arguments to functions? 
For example, which register holds 13 in main's call to printf? 

Answer: a0, a1, a2. a2 contains the argument to printf.

2、Where is the call to function f in the assembly code for main? 
Where is the call to g? (Hint: the compiler may inline functions.)

Answer:In the assembly code of main, there is no call to f. 
There are no jal or call instructions that jump to the address 0x12 of f.
The reason is that the compiler inlined the function f into the main function, 
and then performed constant folding(常数折叠) as well.
There is no call to g found in the assembly code of f either.

3、At what address is the function printf located? 

Answer: 0x73e is the address of printf.

4、What value is in the register ra just after the jalr to printf in main? 

Answer: 0x3c.

5、Run the following code.

	unsigned int i = 0x00646c72;
	printf("H%x Wo%s", 57616, (char *) &i);
      

What is the output? Here's an ASCII table that maps bytes to characters.
The output depends on that fact that the RISC-V is little-endian. 

If the RISC-V were instead big-endian what would you set i to in order to yield the same output? 
Would you need to change 57616 to a different value?

Answer: The output is "He110 World". 
If the RISC-V were big-endian, you would need to set i to 0x726c6400. 
Yes, It doesn't need to change 57616.

6、In the following code, what is going to be printed after 'y='? 
(note: the answer is not a specific value.) Why does this happen?
    printf("x=%d y=%d", 3);
Answer: The value of y is a random and uncertain random number. 
This happens because Typical undefined behavior（T-UB） when the number of printf parameters does not match the format string.
